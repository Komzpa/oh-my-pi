`agent://<id>`: output (status + progress while unpublished); nested IDs dotted, `/key/index` JSON path; write = message, `agent://all` broadcast only. Write to `agent://peer:<sessionId>` to reply to a live sender through the local peer-session transport. Write to the advertised `agent://shell:<id>` to deliver a reply to a shell sender's durable inbox; the sender reads it with `omp peers inbox shell:<id> [--json]` after `omp peers send` exits.
