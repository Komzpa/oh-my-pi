# Requirement ledger completion contracts

- A mapping failure must reject receipts even when saved TODO timestamps match. The saved-row-history fallback applies only when artifact resolution succeeded.
- Every split receipt row must echo the complete immutable parent ask. Sub-IDs partition evidence, not the user quote; partial or reworded echoes cannot authenticate a pass.
- Reloading a background auditor assignment must preserve its exact assigned TODO rows. A receipt for another row cannot be accepted.
- Error and abort finalization must suppress unverified retained narrative when requirements remain open, preserving provider stop/error metadata. Quieted user notices and tool calls must not expose failed narrative.
- A later user restatement explicitly naming the missing-image requirement can be associated by classifying the blocked requirement as merged into that new candidate. Both raw asks remain in audit inputs; rows transfer and old verdicts are discarded. A fresh audit is required. Unrelated or older candidates cannot resolve a blocked linked image requirement.
- Filesystem and path Node APIs use namespace imports as required by AGENTS.md.
- Gate artifact display replaces the home directory with `~` through the centralized shortenPath helper.
